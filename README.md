# JavaScript Web Assignment

Kho bài học và bài tập thực hành JavaScript trên trình duyệt. Nội dung đi từ nền tảng ngôn ngữ đến DOM, xử lý sự kiện, cấu trúc dữ liệu và xây dựng các ứng dụng web nhỏ.

## Mục tiêu học tập

- Nắm các khái niệm JavaScript cơ bản: biến, kiểu dữ liệu, hàm, mảng và object.
- Thực hành thao tác DOM và xử lý sự kiện người dùng.
- Làm quen với các tính năng hiện đại của JavaScript như destructuring, spread/rest và string methods.
- Rèn luyện cách tổ chức HTML, CSS và JavaScript trong các bài tập có giao diện thực tế.

## Nội dung

| Thư mục | Nội dung |
| --- | --- |
| `Session01_JavaScript_Fundamental_1` | Nền tảng JavaScript phần 1 |
| `Session02_JavaScript_Fundamental_2` | Nền tảng JavaScript phần 2 |
| `Session03_DOM_Events` | DOM, events và các mini game |
| `Session04_DataStructures_ModernOperators_String` | Cấu trúc dữ liệu, toán tử hiện đại và xử lý chuỗi |
| `JavaScript_Fundamental_1_Challenge` | Bài thử thách JavaScript nền tảng phần 1 |
| `JavaScript_Fundamental_2_Challenge` | Bài thử thách JavaScript nền tảng phần 2 |
| `DOM_Assignment1` | Bài tập tổng hợp về DOM |
| `CinemaSeat_Student` | Ứng dụng đặt chỗ xem phim |
| `Meal_Craft` | Ứng dụng công thức món ăn |
| `QuickBite_Café` | Giao diện ứng dụng đặt món |

## Cách chạy

1. Clone repository về máy.
2. Mở thư mục dự án bằng VS Code.
3. Mở file `index.html` của bài muốn học bằng trình duyệt, hoặc dùng extension **Live Server**.
4. Tương tác với giao diện và xem mã trong `script.js` để theo dõi cách chương trình hoạt động.

Các bài tập hiện là dự án frontend thuần nên không cần cài dependency hay chạy lệnh build.
